# Sigil Factory — 工場ノード / ライン仕様書

更新日: 2026-08-19

この文書は、工場盤面・ノード・ポート・ライン・配線補助設備に関する詳細仕様をまとめる。
工場ノード / ライン関連の具体仕様については `GAME_DESIGN.md` の概要より本書を優先する。

---

## 1. 工場盤面の基本構成

### 1.1 初期配置

工場盤面は、**中央に召喚器を配置し、その周囲に素材源を配置した放射状の構成**を基本とする。

```text
        [素材源]

[素材源]      [素材源]

        [召喚器]

[素材源]      [素材源]

        [素材源]
```

プレイヤーは外周の素材源から中央の召喚器へ向かって、加工器・合成器・補助設備・ラインを配置してグリフの生産経路を構築する。

### 1.2 盤面拡張

- ゲーム開始時の工場盤面は比較的小さい
- ステージクリアやラン進行に応じて、利用可能な盤面領域が少しずつ外側へ拡張する
- 新しい素材源や配置余地が増えることで、より複雑な高位シジル用ラインを構築できるようにする
- 工場全体が中心へ収束する巨大な魔導回路 / 魔法陣のように見えることを狙う
- 初期実装では均等に外側へ広がる方式を基本とし、方向を選ぶ拡張は将来候補とする

## 2. ノードの基本UI

### 2.1 方向非依存ノード

一般的な「左入力 / 右出力」のノードUIは採用しない。

ノード自体は特定方向を持たず、上下左右・斜めを含め、どの方向から接続しても入力 / 出力を識別できる形にする。

ノード形状は横長矩形より、**円形または小型の魔導装置**を基本候補とする。

### 2.2 入力 / 出力ポート

入力と出力は色ではなく、**形状の違い**で常時識別できるようにする。

理由:

- 属性色とUI色の競合を避ける
- 白線主体のアートでも判別できる
- 色覚差に依存しない

候補:

- 入力: 受け口 / 凹形 / 内向き記号
- 出力: 放出口 / 突起 / 外向き記号

具体的な字形はアート検証で決定する。

### 2.3 ポート位置

ポート位置をプレイヤーが手動調整する操作は持たせない。

- ライン接続方向に応じて、ノード外周の適切な位置へ自動配置する
- ノード自体を回転してポート方向を合わせる操作は不要とする
- 接続状態が変わった場合も、可読性を保つ範囲でポート位置を自動調整してよい

これにより、戦闘中の時間停止編集でも素早く再配線できるようにする。

### 2.4 接続操作

- 出力からドラッグして入力へ接続する操作を基本とする
- 接続操作中は接続可能な入力ポートのみ強調表示する
- 出力同士、入力同士、型不一致などの無効な接続は確定できない
- 接続前に直線ラインと必要魔力をプレビューする

### 2.5 基本ポート数

初期仕様は以下を基本とする。

| ノード | 入力 | 出力 |
| --- | ---: | ---: |
| 加工器 | 1 | 1 |
| 合成器 | 2 | 1 |
| 中継ノード | 1 | 1 |
| 分配器 | 1 | 2 |
| 切替器 | 1 | 2 |
| 召喚器 | 多入力 | なし |

召喚器の入力上限は、初期候補として **8入力程度** を想定し、盤面密度を見て調整する。

## 3. ライン

### 3.1 直線接続

通常ラインは、**接続した2ノード間を常に1本の直線で結ぶ**。

```text
[素材源] ───────── [加工器]
```

プレイヤーがライン自体を曲線・折れ線として編集する操作は持たせない。
ライン形状はノード配置だけから決まる。

この方式により、工場編集の基本操作を以下に絞る。

```text
ノードを配置
  ↓
ノード同士を接続
  ↓
直線ラインが生成
```

### 3.2 基本ルール

- ラインはノード間を接続し、グリフを輸送する
- ラインは盤面上の空間を占有する
- 通常ライン同士の重複・交差は禁止する
- 通常ラインは他ノード本体とも交差できない
- 1本のライン上には複数種類のグリフを混在させない
- 前方が詰まった場合は後続グリフも停止する
- ライン長に応じて工場用魔力を使用する
- ライン削除時には使用魔力が戻る

### 3.3 流れる方向の表示

入力 / 出力ポートだけでなく、ライン自体にも流向を表示する。

- 静止時: 小さな矢印や方向マーカーをライン上へ表示
- 稼働時: 実際にグリフが移動することで流向を視覚化

ポート形状、ライン方向表示、グリフ移動の3段階で、どの向きに流れているかを理解できるようにする。

### 3.4 グリフの配置と詰まり

- ライン上には複数グリフが一定間隔で実際に並んで流れる表現を基本とする
- 前方が停止した場合は、その後ろのグリフも順番に停止する
- 見た目から詰まり箇所と流量を把握できることを優先する
- 具体的な間隔、速度、ライン容量はプロトタイプで決定する

## 4. 中継ノード

### 4.1 目的

通常ラインは必ず直線であるため、障害物や別ラインを避けて迂回したい場合は、**中継ノードを配置して直線を複数本に分ける**。

```text
[素材源] ─── [中継]
                  \
                   \
                  [加工器]
```

### 4.2 ルール

- 1入力 / 1出力
- グリフを加工しない
- グリフの種類を変更しない
- 処理時間を持たない
- 配線経路を作ることだけが役割
- 中継ノード自体の魔力コストは無料またはごく低コストを第一候補とする
- 中継によって総ライン長が増えた分の魔力コストは通常通り発生する

ライン上に不可視の制御点を置くのではなく、中継位置も盤面上の明示的な要素として可視化する。

---

## 5. 初期の配線補助設備

初期の補助設備は増やしすぎず、以下を基本セットとする。

| 補助 | 役割 |
| --- | --- |
| 中継ノード | 直線ラインを複数本に分けて迂回経路を作る |
| 分配器 | 1入力を複数出力へ順番に振り分ける |
| 切替器 | 複数出力のうち1つだけを選んで流す |
| 異相門 | ラインを一時的に別位相へ通し、他ラインを跨ぐ |

---

## 6. 分配器

### 6.1 基本動作

1本の入力ラインから受け取ったグリフを、2本の出力ラインへ振り分ける。

**グリフを複製する設備ではない。**

初期仕様はラウンドロビンを基本とする。

```text
               ┌→ 出力A
入力 → [分配器]
               └→ 出力B

1個目 → A
2個目 → B
3個目 → A
4個目 → B
```

### 6.2 出力が詰まった場合

通常のラウンドロビン順は維持するが、次の出力が受け取り不能な場合は、**送れるもう一方の出力へ送る**。

```text
A: 詰まり
B: 空き

→ Bへ送る
```

片方の出力閉塞だけで分配器全体が停止する状態を避ける。
両方の出力が受け取れない場合のみ停止する。

### 6.3 用途

同じ中間グリフを、低位シジル召喚と高位シジルの追加加工へ分ける用途などを想定する。

```text
素材源
  ↓
加工器
  ↓
分配器
 ├→ 低位シジル → 召喚器
 └→ 追加加工 → 高位シジル → 召喚器
```

これにより、生産能力をどこへ配分するかという判断を作る。

## 7. 切替器

### 7.1 基本動作

1本の入力に対して2本の出力候補を持ち、**選択されている1系統にだけグリフを流す**。

```text
               ┌→ ラインA
入力 → [切替器]
               └→ ラインB
```

分配器との違い:

- 分配器: 複数ラインを同時運用する
- 切替器: その時点では1つのラインだけを運用する

### 7.2 戦況対応

出力先の変更は**時間停止中のみ**可能とする。

```text
基本グリフ
  ↓
切替器
 ├→ 大型化ライン → 大型召喚獣
 └→ 別加工ライン → 群体召喚獣
```

通常戦闘中に即時切替できるようにはせず、時間停止 / 再構成システムの一部として扱う。

戦況を見て毎回ラインを撤去するだけでなく、**将来の切替を見越した工場を事前設計する**というプレイヤースキルを作る。

## 8. 異相門（仮称）

### 8.1 目的

通常ラインの交差禁止を維持しつつ、どうしても越えられない既存ラインを跨ぐための特殊設備。

一般的なコンベアゲームの地下ベルトに相当するが、世界観上は**一時的に別位相へグリフを送る**表現とする。

```text
通常ラインA
────────────────

ラインB
── [異相門入口] ··· [異相門出口] ──
```

### 8.2 入口 / 出口の一括配置

異相門は入口と出口を別々の設備として購入・配置するのではなく、**入口と出口のペア全体を1つの設備として配置する**。

操作例:

```text
異相門を選択
  ↓
入口位置を指定
  ↓
出口位置を指定
  ↓
1つの異相門として確定
```

内部的にも1オブジェクトとして扱う。

```text
PhaseGate {
  entrance
  exit
}
```

これにより複数の異相門を置いた場合でも、どの入口と出口が対応しているかを明確にする。

### 8.3 魔力コスト

- 入口 / 出口それぞれに別料金を設定しない
- **1ペア全体に対して1つの固定魔力コスト**を設定する
- 必要であれば、異相距離に応じた追加コストを別途検討する

### 8.4 基本制約

- 1異相門 = 入口1 + 出口1の固定ペア
- 異相区間は通常ラインとの交差判定を無視する
- 異相区間同士の交差も許可する
- 異相区間の途中では分岐できない
- 異相区間の途中へ加工器・合成器・補助ノードを配置できない
- 中間地点から出入りできない
- グリフは入口から入り、対応する出口から同一状態で出る
- 最大距離を設けるかは盤面サイズと実際の使用感を見て決定する

異相門は通常配線より便利だが、すべてを異相門で接続することが最適にならないコスト設定を行う。

### 8.5 表現

- グリフが入口で消え、出口から再出現する
- 入口 / 出口は魔術的な門・裂け目・環として表示する
- 入口と出口の対応は薄い点線、残像、固有マーカーなどで確認可能にする
- 対応表示には属性色との競合を避けるため、色だけに依存しない

## 9. ノードのバッファと閉塞

### 9.1 出力バッファ

通常設備は、処理完了後のグリフを**出力側に1個だけ保持できる**ことを基本とする。

```text
入力
 ↓
加工
 ↓
完成グリフ
 ↓
出力ラインが詰まっている
 ↓
ノード内に1個保持
 ↓
設備停止
```

保持中は次のグリフ処理を開始しない。

### 9.2 閉塞の伝播

- 出力バッファが埋まる
- 設備が停止する
- 入力側が受け取れなくなる
- 上流ラインも順番に詰まる

という挙動を基本とする。

詰まりをファクトリーゲームの読み取れる状態として視覚化する。

## 10. 工場編集時の仕掛品

- 時間停止中にラインやノードを仮削除しても、確定するまでは元状態を保持する
- 編集確定時に削除されたライン上・設備内に存在していたグリフは廃棄する
- 廃棄されるグリフの数・種類は確定前に表示する
- 魔力は設備 / ライン削除に応じて戻るが、廃棄された仕掛品は素材へ戻さない

これにより大規模な再構成には生産上の小さな損失が生じるが、編集操作そのものには追加通貨を要求しない。

## 11. 後から追加する補助設備候補

以下は初期セットには含めず、必要性が確認された場合やローグライトの上位設備として追加を検討する。

### 11.1 優先分配器

```text
               ┌→ 優先ライン
入力 → [優先]
               └→ 余剰ライン
```

- 優先出力が受け取れる限り、そちらへ送る
- 優先出力が詰まった場合だけ、もう一方へ送る

例: 高位シジル生産を優先し、余った中間グリフだけ低位召喚へ回す。

### 11.2 比率分配器

出力比率を指定できる分配器。

候補:

```text
50 : 50
75 : 25
100 : 0
```

通常分配器より理解・調整項目が増えるため、最初からは導入しない。

### 11.3 バッファ

複数個のグリフを意図的に一時保管する専用設備。

```text
素材 → 加工 → [バッファ] → 加工
```

通常設備の1個出力バッファとは別物とする。

戦況変化時に蓄積した中間グリフを切替ラインへ流すなどの戦術が可能になるが、物流ゲーム寄りの管理要素が強くなるため、中心ループで必要性が確認されてから追加する。

## 12. 原則として導入しない設備

### 12.1 通常の合流器

物流だけを目的とした複数入力 → 1出力の合流器は、原則として導入しない。

理由:

- 複数グリフを1グリフへまとめる意味のある処理はすでに**合成器**が担う
- 合流と合成の違いが分かりづらくなる
- 1本のラインへ複数種類のグリフを混在させないルールと衝突しやすい

### 12.2 通常の複製器

入力グリフ1個を複数個へコピーする通常設備は導入しない。

```text
A → 複製 → A + A
```

を自由に行えると素材源の生成速度や分配判断の意味が弱くなるため。

特殊なリリック・能力・高コスト設備として例外的に導入する余地は残す。

---

## 13. 補助設備の設計原則

- 加工器 / 合成器 / 召喚器が工場の主役であり、補助設備を増やしすぎない
- **1ノード1機能**を基本とする
- 分配器は分ける、切替器は選ぶ、異相門は跨ぐ、という役割を混ぜない
- 高度な物流挙動は万能ノード1個ではなく、複数ノードの組み合わせで作ることを基本とする
- 補助設備は「物流を自動化するため」より、**空間制約と戦況対応に選択肢を作るため**に導入する
- ライン交差禁止は重要なパズル制約として残す
- 異相門などの回避手段は、交差禁止を無意味にしないコスト / 制約を持たせる
- 将来の敵構成を予測して、分配器・切替器を含む柔軟な工場を設計する価値を作る
- 補助設備を使わず、単純な短いラインを作ることにも魔力・面積効率上の価値を残す

# Sigil Factory — ローグライト進行 / ステージ報酬仕様

更新日: 2026-08-19

この文書は、ローグライト進行、ステージ報酬、素材源の増加、敵召喚ルールに関する詳細仕様をまとめる。
これらの具体仕様については `GAME_DESIGN.md` の概要より本書を優先する。

---

## 1. 基本方針

ローグライト進行では、単純な数値強化を積み重ねるだけでなく、**取得した報酬によって工場の最適構成そのものが変化すること**を重視する。

プレイヤーはルートマップ上で次のステージ候補を見て、

1. どの報酬カテゴリが欲しいか
2. そのカテゴリの中で何を取得するか

の二段階でビルドを形成する。

```text
ルート選択
  ↓
報酬カテゴリを選ぶ
  ↓
ステージ攻略
  ↓
カテゴリ内の候補から報酬を選ぶ
  ↓
工場を再構成
```

## 2. ステージごとの報酬カテゴリ

### 2.1 事前表示

各戦闘ステージには、クリア時に得られる**報酬カテゴリ**をあらかじめ設定し、ルートマップ上で表示する。

例:

```text
        [シジル]
       /
開始 ── [素材源] ── [強敵: リリック]
       \
        [加工器]
```

プレイヤーは現在の工場・所持シジル・今後の進化を見ながら進路を決める。

### 2.2 基本カテゴリ

初期の主要カテゴリは以下とする。

| カテゴリ | 主な報酬 |
| --- | --- |
| シジル | 新しいシジル、シジル系統の拡張 |
| 素材源 | 新Primitiveの素材源、既存Primitiveの追加素材源 |
| 加工器 | 新しい加工能力、加工器関連の拡張 |
| リリック | 工場・召喚・戦闘ルールやビルドを変化させる特殊強化 |
| 魔力 | 最大魔力など工場容量に関する強化 |
| イベント | 交換、特殊選択、複合報酬など |

カテゴリ数は必要以上に増やさない。

### 2.3 カテゴリ内選択

ステージクリア後は、そのステージに設定されたカテゴリ内から複数候補を提示し、1つを選択する。

初期候補数は **2〜3択** とする。

例: 素材源ステージ

```text
素材源報酬

A. 新Primitive「鉤」の素材源
B. 新Primitive「枝」の素材源
C. 既存Primitive「牙」の素材源を追加
```

これにより、ルート選択とクリア後選択の両方に判断を持たせる。

## 3. リリックとリーダー

### 3.1 リーダー能力は独立した成長カテゴリにしない

従来検討していた「リーダー能力」は、リリックと役割が重複するため独立した報酬カテゴリとしては採用しない。

- リーダーは戦場上の勝敗条件として存在する
- ラン中の特殊強化は**リリックへ統合**する
- 「リーダー能力」という別の強化プールは設けない

これにより、プレイヤーが覚える成長カテゴリを減らし、特殊効果の役割をリリックへ集約する。

### 3.2 リリックの役割

リリックは、単純なステータス上昇だけではなく、**工場や召喚の最適構成を変化させる特殊効果**を中心とする。

例:

- 加工工程が少ないシジルを強化
- 合成を一定回数以上含むシジルを強化
- 特定色を含むシジルへ追加効果
- 低位シジルを一定数召喚するたびに追加効果
- 分配器を通ったグリフから召喚されたユニットを強化
- 特定加工器の魔力コストを軽減

リリックによって、通常は高位シジルを優先する状況でも、低位大量召喚などの例外的なビルドが成立する余地を作る。

## 4. 盤面拡張

### 4.1 ラン進行による保証成長

工場盤面の拡張は、通常のランダム報酬カテゴリにはしない。

エリア進行やボス撃破などの固定タイミングで、盤面が外側へ段階的に拡張する。

```text
開始時の小さな盤面
  ↓
エリア進行
  ↓
外周を拡張
  ↓
さらに複雑な工場を構築可能
```

盤面拡張を任意報酬にすると、取得しなかった結果として高位シジルを物理的に配置できない事故が起こり得るため、基本的な成長として保証する。

### 4.2 空の素材源スロット

盤面が拡張されると、外周に新しい**素材源スロット**が解放される。

```text
          [空]     [空]

      素材A           素材B

              召喚器

      素材C           [空]

          [空]     [空]
```

素材源報酬を取得することで、このスロットへ新しい素材源が追加されていく。

## 5. 素材源の増加

### 5.1 素材源は固定配置

素材源はプレイヤーが自由な位置へ配置する設備にはしない。

- 盤面外周に素材源スロットが存在する
- 新しい素材源は空きスロットへ固定配置される
- 一度配置された素材源は通常のノードのように移動しない

これにより、素材源の位置そのものを工場パズルの条件として残す。

### 5.2 種類を選び、位置はシステム側で決める

素材源報酬では、プレイヤーは**追加するPrimitiveの種類**を選択する。

配置先は、次に解放される素材源スロットとして事前に示す。

例:

```text
次の素材源位置: 北東外周

A. 鉤
B. 枝
C. 牙
```

これにより、位置まで完全自由にして空間制約を弱めることなく、将来の工場配置を予測して選択できる。

### 5.3 同じPrimitiveの素材源を複数取得できる

新しい素材だけでなく、既存Primitiveの素材源を追加する選択肢も用意する。

```text
牙素材源 ×1
  ↓
素材源報酬で再取得
  ↓
牙素材源 ×2
```

これは新しいシジル系統を開く選択とは異なり、**既存ラインの生産量を増やす選択**として機能する。

素材源報酬では、

- 新しいPrimitiveを得て工場の選択肢を広げる
- 既存Primitiveを追加して現在のビルドを高速化する

というトレードオフを作る。

## 6. 敵召喚ルール

### 6.1 敵側に工場シミュレーションは持たせない

敵側はプレイヤーと同じ工場を内部で構築・稼働させない。

代わりに各敵召喚門が、ステージ開始時に決定された**仮想生産スケジュール**に従って敵ユニットを召喚する。

例:

```text
敵召喚門A
- 小型近接: 5秒周期
- 盾兵: 20秒周期

敵召喚門B
- 遠距離兵: 8秒周期
```

敵にも一定の生産制約が存在するように見せつつ、不要な工場シミュレーションを省く。

### 6.2 敵召喚門ごとに役割を持たせる

各敵召喚門には、基本的な兵種・役割を持たせる。

例:

| 召喚門 | 主な役割 |
| --- | --- |
| Gate A | 小型大量生産 |
| Gate B | 遠距離支援 |
| Gate C | 大型 / 攻城 |

これにより「どの召喚門を先に破壊するか」という戦場側の攻略判断を作る。

敵召喚門を破壊すると、その門からの供給は停止し、既存仕様どおり周辺の自陣化へつながる。

### 6.3 プレイヤーへのリアクティブなカウンターは行わない

敵編成は、プレイヤーが現在生産している召喚獣を見て自動的に最適なカウンターへ変更しない。

```text
プレイヤーが飛行兵を生産
  ↓
敵が自動で対空兵へ切替
```

のような挙動は基本的に採用しない。

敵スケジュールはステージ開始時に決定済み、またはステージシードから決定可能なものとする。

プレイヤーは提示された情報を読み、工場を組み替えて対策する。

## 7. 敵召喚の予告

### 7.1 ステージ開始前

ステージ開始前には、少なくとも以下を公開する。

- 敵召喚門の位置
- 各召喚門から出現し得る主な兵種
- 敵全体の特徴
- 大きな脅威の傾向

ただし、全出現時刻と全個体数をステージ開始前から完全公開する必要はない。

### 7.2 戦闘中の予告階層

予告は時間距離に応じて精度を変える。

**直近20〜30秒程度**

- 敵種
- おおよその数または編成
- 出現タイミング
- 対象の召喚門

をかなり正確に表示する。

**45〜60秒程度先の大きな編成変化**

```text
⚠ 装甲部隊接近
⚠ 飛行部隊接近
```

のように、対処方針を考えられる警告を出す。

**さらに先**

```text
大群の兆候
大型魔力反応
飛行反応
```

のような曖昧な予兆だけを提示してよい。

具体的な秒数は工場の生産・輸送・前線到達時間を計測した上で調整する。

### 7.3 目的

この予告方式により、

```text
ステージ開始前
  ↓
敵の大まかな構成を見て工場を設計
  ↓
戦闘開始
  ↓
具体的な次の脅威を確認
  ↓
必要なら時間停止して工場を変更
  ↓
新しい召喚獣が前線へ到達
```

という、本作の中心となる「予測 → 再構成 → 戦況変化」を成立させる。

## 8. 設計原則

- 報酬カテゴリはルート選択前に分かるようにする
- クリア後はカテゴリ内で複数候補から選ぶ
- リーダー能力とリリックを重複させず、特殊強化はリリックへ統合する
- 盤面拡張はラン進行による保証成長とする
- 素材源の位置は固定し、素材源配置そのものを工場パズルとして残す
- 同一Primitiveの素材源を複数取得可能にし、種類の拡張と生産量強化を選べるようにする
- 敵はプレイヤーに後出しカウンターせず、事前決定されたスケジュールを予告する
- 敵召喚門ごとの役割を明確にし、破壊順に意味を持たせる
- 強化要素を増やしても、基礎リソースや報酬カテゴリそのものは必要以上に増やさない
